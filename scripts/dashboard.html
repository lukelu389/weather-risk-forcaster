Read the experiment limits

The final holdout is consumed. Rolling fits admit previous final-period labels only after maturity. Missing quote rows remain missing, and the horizon follows variable quote intervals. WTI uses USD/barrel changes; other targets use percentage log returns. Scores cannot be ranked across those units.

The original 1,000-draw bootstrap cannot attain p-values below the first Holm thresholds for its 165 score comparisons or 54 ES diagnostics. The 19,999-draw correction preserves every model, hypothesis, block rule and seed and is labelled post-exposure. Non-rejection does not establish equivalence or calibration.

CAD sensitivities reset CAD 1 million at each interval start with four equal equity weights. Costs are fixed budgets applied to both realized and forecast losses. This is not compounded wealth, a futures/FX portfolio, or estimated transaction-cost performance. The pilot does not cover 2008 or 2014–2016.
