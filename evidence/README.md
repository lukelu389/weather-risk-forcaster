# Public evidence verification

Run `make verify-results` from the repository root. This needs Python 3.11+ only.
No network, credentials, GPU, provider dataset or model training is involved.

The verifier checks SHA-256 digests for the published artifacts, checks the 20
available files bound by the original protocol seal, and recomputes 54 VaR
coverage rows from 27,882 categorical forecast events. It independently computes
event counts and rates, adjacent-state transitions, exact two-sided binomial
p-values, unconditional/independence/conditional likelihood-ratio tests, and
their Holm adjustments. Unavailable grid positions remain explicit; the
verification never connects transitions across a missing row.

It also recalculates Holm adjustments from the saved primary and supplementary
ES/paired-score p-values and checks the reported rejection counts. The
19,999-draw sensitivity has three adjusted ES rejections, one adjusted score
comparison rejection and zero matched-weather rejections. These checks do not
rerun the bootstrap or establish that unavailable raw inputs were correct.

## Files and provenance

| File | Purpose |
|---|---|
| `manifest.json` | Digest inventory for public derived evidence and archived implementation |
| `coverage-events.csv.gz` | Asset, date, original grid index, model, confidence, common-valid flag and strict VaR exception flag |
| `publication-changes.json` | Original/public hashes for sanitized provenance copies and report subset manifests |
| `../scripts/export_coverage_events.py` | Deterministic export from the checksum-pinned private forecast artifact |
| `../scripts/verify_results.py` | Independent standard-library checker |

An exception means realized loss exceeded forecast VaR strictly. Empty exception
flags are unavailable observations, not zero losses or successful forecasts.
The event file contains no prices, returns, forecast magnitudes or fitted weights.
It cannot recover the underlying price series, ES residuals, forecast losses or
the original model fits. Binary exception flags are still derived empirical
evidence, not synthetic observations.

The manifest pins the original forecast CSV and final-run manifest hashes. A
reviewer can check computations on the published classifications, but cannot
validate classification against private raw forecasts from this public subset.
Hashes establish consistency and detect accidental changes; they are not an
external attestation of the research or its timing.

Report manifests are explicitly labelled `published_subset`. Their `artifacts`
map covers the included files, while `original_manifest_sha256` identifies the
preserved full private manifest. Other historical provenance hashes continue to
refer to the original experiment. Workstation prefixes were removed from public
copies; numeric tables, plots, the committee memo and original seal are unchanged.
The original workspace and its complete manifests were not rewritten.

Exact binomial confidence intervals, forecast-score means, ES residuals and
bootstrap distributions remain published original results; they are integrity
checked but are not independently regenerated by this categorical verifier.
The four private input files in the seal are deliberately absent. See
[the data policy](../docs/data-policy.md) for the full-refit boundary.
